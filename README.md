## About me

I'm **Kelvin Santos**, an **IT Infrastructure & Support Analyst** based in São Paulo, Brazil, currently studying **Computer Science at UNINOVE**.

- 🖥️ Focused on IT operations, systems administration and production environment support
- 🛠️ Supporting service continuity through incident handling, troubleshooting and preventive maintenance
- 🔐 Working with Active Directory, Microsoft 365, Entra ID, IAM and access control
- ☁️ Building practical knowledge across Azure, AWS and hybrid infrastructure
- ⚙️ Automating repetitive operational tasks with PowerShell and Python

## Career objective

My goal is to grow in **IT Operations & Systems**, working with infrastructure operations support, systems administration, identity and access management, cloud services, incident response and operational automation. I aim to help keep business-critical environments **stable, secure, available and continuously improving**.

**Target roles:** IT Operations Analyst • Systems Analyst • Infrastructure Analyst • Systems Administrator • Cloud Support Analyst
